# 📖 Overview

**India in the World** is an interactive web application that brings together globally recognized development indicators into a single platform, making it easier to explore India's position in the world.

Instead of navigating multiple reports published by organizations such as the World Bank, users can view important metrics in one place and compare India's performance with countries across the globe.

The platform combines modern data visualization with an AI-powered assistant to help users better understand economic, social, technological, and governance-related indicators.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/your-username/India_In_The_World.git
```

## Navigate to the project

```bash
cd India_In_The_World
```

## Install dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file and add your Supabase credentials.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

If using Bharat AI, configure the required API keys in your Supabase project secrets.

---

## Start the development server

```bash
npm run dev
```
